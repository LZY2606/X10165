# 增量索引模拟器

一个小型实验环境，用于验证增量索引在**文档变化、解析规则升级、依赖关系改变**时究竟会失效哪些派生项。

## 运行

```bash
corepack enable && pnpm install --frozen-lockfile
pnpm test -- --run          # 运行全部测试
pnpm dev -- --host 127.0.0.1 --port 5237
# 浏览器打开 http://127.0.0.1:5237
```

## 模型

- **文档节点**：路径 + 内容 + 跨文档引用。
- **token 提取器**：从文档内容提取 token（依赖解析器版本）。
- **派生视图**：声明依赖、敏感度（内容派生 / 路径敏感）、是否依赖解析器版本。
- **变更集**：一批文档/引用/视图/解析器变更，以单个 revision 发布。

## 核心语义

- **改名复用**：内容相同仅路径变化时，内容派生节点签名不变（复用），路径敏感节点失效。
- **解析器升级**：只有声明依赖解析器版本的节点（及下游）失效。
- **删除墓碑**：删除文档产生墓碑，旧引用保持可见（悬挂），直到一次一致性重算完成后才被回收。
- **快照隔离**：计划基于其 revision 的冻结快照执行；期间到达的新 revision 不会混入，计划完成时标记“已过时”，仅把结果安全应用到签名未变的节点。
- **环形固定点**：依赖环按 SCC 归为固定点组，以稳定顺序迭代；预算耗尽时保存中间状态与诊断，不宣称成功，可用更高预算恢复。
- **持久化与恢复**：revision、计划、执行事件全部持久化（浏览器 localStorage）；崩溃后从最后一个完整阶段继续。
- **导出/导入**：确定性序列化，导出导入后计划顺序与索引摘要逐字节一致。

## 目录

- `src/core/` — 引擎（签名、失效传播、SCC 固定点、执行器、持久化）
- `src/ui/` — 网页（编辑、变更集、传播动画、重算、revision 比较、导入导出）
- `tests/` — 改名复用、路径敏感、解析器升级、删除墓碑、快照隔离、环形固定点、预算耗尽、阶段恢复、导出导入
